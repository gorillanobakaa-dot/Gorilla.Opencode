SOURCE ATLAS — free research sources by domain, strongest first.
Reach: API = keyless HTTP API (web_fetch the endpoint). API-key = free after registration —
say so if unavailable. SearXNG = web_search engine bang (e.g. !crossref, !openalex, !pubmed,
!arxiv, "!google scholar"). SearXNG* = installed but off; note it for the user. Grade A/B is
the source-reliability PRIOR; claims are still graded independently at vetting.
This is the starting map, not the boundary — the full 985-source registry ships in docs/.

Scholarly & scientific literature:
  OpenAlex [A API] api.openalex.org
  Crossref [A API] api.crossref.org
  arXiv [A API] export.arxiv.org/api/query — physics, maths, CS, quantitative biology;
    full text free. The first place to look for anything computational or theoretical.
  bioRxiv / medRxiv [A API] api.biorxiv.org — preprints, unreviewed BY DEFINITION: grade
    the source accordingly and say it is a preprint in the finding.
  PsyArXiv [A API] api.osf.io/v2
  Semantic Scholar [A SearXNG] www.semanticscholar.org
  Google Scholar [B SearXNG] scholar.google.com
