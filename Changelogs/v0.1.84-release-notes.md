# v0.1.84 — 2026-08-15 — quota warning messages now scream in bright red

**Modified:** 26-08-15-10-27  
**File changed:** `internal/tui/tui.go` — `formatQuotaScrollbackLine`

---

## What changed and why

### Plain-language version

Every time your quota drops through a tier boundary — from "loaded" to "halfway",
or from "halfway" to "running low" — gorilla-opencode prints a timestamped line
in the scrollback:

```
10:27:38  quota · 🍌🍌 Running low on bananas... — Claude and GPT models: 47% left
```

Before this release that line appeared in plain terminal-default white. It was
sitting in the scroll history looking like any other output — easy to skip, easy
to miss. The whole point of that message is to catch your attention *before*
you burn the last of your quota by accident.

The line is now **bold and bright red (`#FF0000`)**. Both kinds of quota message
are affected:

- **Tier-crossing alerts** — the automatic warnings that fire after each response
  when the banana tier drops (e.g. first time you cross below 50%).
- **The `/usage` summary line** — the single-line timestamp that heads the full
  quota panel when you type `/usage`.

### Technical version

`formatQuotaScrollbackLine(at time.Time, line string) string` in
`internal/tui/tui.go` is the single function both message paths go through before
reaching `tea.Println`. A package-level lipgloss style was added:

```go
var quotaAlertStyle = lipgloss.NewStyle().Bold(true).Foreground(lipgloss.Color("#FF0000"))

func formatQuotaScrollbackLine(at time.Time, line string) string {
    return quotaAlertStyle.Render("  " + at.Format("15:04:05") + "  quota · " + line)
}
```

`tea.Println` writes raw bytes above the inline frame — it bypasses the TUI
renderer and the theme entirely. The theme's `WarningColor` (changed to `#FF0000`
in commit 0787f7b, v0.1.83) reaches the footer status bar via `t.Warning()` but
has no effect on `tea.Println` output. The style must be embedded in the string
before it is handed to `tea.Println`.

Both call sites route through `formatQuotaScrollbackLine`:

- `case quotaLineMsg:` — `/usage` reading (line 573 of `tui.go`)
- `case quotaAlertMsg:` — tier-crossing alert (line 595 of `tui.go`)

No other files were changed.

---

## What was NOT changed

- The quota bar colours in the `/usage` panel (`quotaHexColor`, the green→red
  gradient) — those are independent and were already correct.
- The footer status bar styling — that was already using `t.Warning()` / `#FF0000`
  since 0787f7b.
- Font size — terminals do not have font sizes. Bold is the correct equivalent.

## Verification

Built clean with `go build`. Binary at repo root confirmed fresh mtime and

plain text; after the fix it carries ANSI bold + `#FF0000` foreground codes.
Confirmed by reading the function output.
