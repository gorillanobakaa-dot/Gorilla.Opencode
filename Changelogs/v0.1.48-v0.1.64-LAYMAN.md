# gorilla-opencode v0.1.64 — The conversation no longer stops dead at the first tool call

**Date:** 2026-07-31
**Previous version:** v0.1.48

---

## Why This Release Exists

Between 28 and 31 July 2026 this program carried a bug that made it close to unusable for real work, and it hid itself well. When the AI used a tool — searching your files, running a command — the answer arrived, was saved to the database, and was never shown to you. The screen sat on "Waiting for response…". On 30 July a command finished in two seconds, the AI wrote its full answer, and the screen showed nothing for fifteen minutes. That is indistinguishable from a stuck connection, so the natural response was to wait, then restart, then blame the provider. Every conversation that used a tool was cut off at its first tool call. That is fixed. Alongside it: a single search could return 2.4 megabytes in one result and quietly wreck your token budget, the context meter read about two hundred times too high, Escape did not stop the AI, and the bar at the bottom of the screen crawled down the window and jumped back up. All fixed, and every one of them was found by measuring rather than by reasoning about the code.

## What You Will Notice

**using any tool**
- Before: the AI's answer never appeared; the screen sat on "Waiting for response…" indefinitely, looking exactly like a hung provider
- After:  tool results, and the answer after them, appear normally
- Affects: everyone

**searching your code**
- Before: one search returned 2,438,026 bytes and took a conversation from 15.9K tokens to 675K in a single turn — and that cost repeated on every turn afterwards
- After:  every tool result is capped at 400 KB, and anything cut short says so
- Affects: everyone

**the context meter**
- Before: read about two hundred times too high; it displayed 387%
- After:  shows the real figure
- Affects: everyone

**pressing Escape**
- Before: did not stop the AI mid-answer
- After:  stops it
- Affects: everyone

**the bar at the bottom of the screen**
- Before: marched down the window and jumped back up, stranding fragments in the transcript
- After:  stays put, because no line in the frame may now be wider than your terminal
- Affects: everyone, worst on narrow windows

**watching the AI think**
- Before: if you asked to see thinking and none came, you got silence and no explanation
- After:  it tells you why there is none, which is usually one setting switched off while its partner is on
- Affects: some users

**recalling what you typed**
- Before: no way to get your previous message back
- After:  Up and Down recall previous messages, like every shell
- Affects: everyone

## Deliberately Not Done

- **The bar at the bottom was still reported to jump after the main fix, and that report is unresolved.** — Two explanations have been tested and disproved, each left behind as a permanent test. The next step is capturing the actual bytes the program emits and replaying them through a terminal emulator, rather than guessing again from a screenshot. Guessing is what cost three earlier releases.
- **The width fix has not been proven across a long real session.** — It is verified by automated test only. It matters most on narrow windows, around 80 columns, and confirming that needs a person using it for a while.
- **One release in this range, v0.1.56, was shipped on a diagnosis that turned out to be wrong.** — The change it made is still worth keeping, so it was not reverted. Its commit message states a cause that is not the real one. That is recorded here rather than quietly corrected, because three independent attempts reached the same wrong answer and the next person will too.

## Privacy & Security

No change to what this program collects, sends, or stores. There is no telemetry, and conversations stay in a database in your home directory. One change matters for cost rather than privacy: every tool result is re-sent to the model on every later turn, so an unbounded result was a repeating charge rather than a one-off. Capping results at 400 KB reduces what leaves your machine on every subsequent turn.

## How to Install

**Before you start:**
- A 64-bit Debian or Ubuntu system
- Permission to install packages (sudo)
- The .deb file and checksums.txt from this release

**Step 1:** Check the download is intact before installing it. Publishing is not proof of a good upload.
```
sha256sum -c checksums.txt
```
✓ Each filename is followed by OK.

**Step 2:** Install the package. Do not copy the binary into place by hand: that leaves the system package database reporting the old version, and then nothing can tell you what is actually installed.
```
sudo dpkg -i gorilla-opencode_0.1.64_amd64.deb
```
✓ dpkg reports unpacking and setting up gorilla-opencode, with no error.

**Step 3:** Confirm the program and the package database agree with each other.
```
gorilla-opencode --version && dpkg -l gorilla-opencode | tail -1
```
✓ Both report 0.1.64. If they disagree, something was installed by hand; reinstall with dpkg.

**To go back:** Install the previous package the same way: sudo dpkg -i gorilla-opencode_0.1.48_amd64.deb. Your settings and saved conversations live in your home directory and are not touched by installing or removing the package.

## If Something Goes Wrong

**The screen sits on "Waiting for response…" and nothing appears after a tool runs.**
The program refused to print anything further once a tool result arrived, so the AI's answer was written to the database and never shown.
What to do: Update to this release.
Status: fixed in v0.1.63

**One search makes the conversation enormously expensive, very suddenly.**
The search limited how many matches it returned but not how much text. Matching inside a file that is one very long line returned megabytes.
What to do: Update to this release; results are now capped by size.
Status: fixed in v0.1.62

**You asked to see the AI think and no thinking appears.**
Two settings work as a pair. If generating thinking is off while showing thinking is on, there is nothing to show. Models that think by default look like they work; models that only think when asked show nothing.
What to do: Switch on "Ask the model to think out loud" in /context. The program now explains this on screen instead of showing nothing.
Status: fixed in v0.1.60

**The bar at the bottom creeps downward and leaves fragments behind.**
A line wider than your terminal wraps onto two rows on screen, but the program counted it as one, so each redraw failed to erase one row.
What to do: Update, and widen the window if it persists.
Status: fixed in v0.1.57; a further report of the bar jumping is still open

## Common Questions

**Q: Why does one release cover so many version numbers?**
A: Sixteen builds were made between 28 and 31 July and none of them were ever published. The work existed only on the machine that built it. This publishes it as one package rather than pretending sixteen separate announcements happened.

**Q: I saw a version 0.2.0 mentioned somewhere. Where did it go?**
A: It was never a real release. The number was invented in error, was never approved, and had no downloadable files attached to it. It has been removed so nothing points at it any more. The documents written under that number were good work and have been kept; only the number is gone.

**Q: Is the program faster now?**
A: No, and nothing here claims it is. It is correct where it was previously silent. The one measurable saving is in tokens, not speed: capping tool results stops a single search from costing hundreds of thousands of tokens on every following turn.

**Q: The instructions sent to the AI got much bigger. Can I turn parts off?**
A: Yes. Every section is individually switchable in /context, and each shows its token cost and a plain sentence saying what you lose. Two sections are marked critical, because turning them off makes the program more likely to claim success it never checked, and the menu tells you that rather than quietly letting you do it.

## Bottom Line

If you are running anything older than this, update. The headline fix is that conversations using tools no longer stop dead at the first tool call, a fault that silently truncated every such conversation and looked exactly like a network problem. Alongside it, a runaway search that could cost hundreds of thousands of tokens is now capped by size, the context meter reports a real number instead of one about two hundred times too high, and Escape stops the AI. The honest caveats are these: the bar at the bottom of the screen is still reported to jump in some situations and that is unresolved, the width fix behind the main footer repair has been proven only by automated test and not by long real use, and one release in this range shipped on a diagnosis that later proved wrong. Those are written here rather than left for you to discover. This release also carries a full rewrite of the instructions sent to the AI, which costs roughly twice as many tokens per turn and can be tuned or switched off section by section.
