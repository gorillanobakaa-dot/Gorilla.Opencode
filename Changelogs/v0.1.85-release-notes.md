# Gorilla Opencode v0.1.85 — fork identity and prompt wrapping

## Plain-language track

You can run the rebuilt fork without confusing its runtime files with an existing upstream OpenCode installation. Configuration, data, cache, and state use XDG directories below branded `gorilla-opencode` roots. Fork-owned database, temporary, export, panic, command, and environment-name paths use the fork identity. Legacy upstream migration reads are not retained because this test-machine release does not preserve the old installation name.

The inline prompt now keeps earlier text visible when a line reaches the terminal edge. The failure came from Bubble Tea reusing a one-row textarea viewport while the prompt grew. The editor now probes a full-height textarea after reapplying the current value, counts the rendered wrapped rows, and restores the live viewport height. The exact long-prompt boundary has a regression test.

## Developer track

### Changed files and responsibilities

| Area | Implementation |
| --- | --- |
| XDG storage | `internal/config/store.go` provides branded configuration, data, cache, and state roots. |
| Runtime naming | `internal/config/config.go`, `internal/db/connect.go`, `internal/fileutil/fileutil.go`, logging, exports, shell temporary files, and command storage use fork-owned names. |
| Footer sizing | `internal/tui/tui.go` derives the inline budget from the rows above the status bar. |
| Editor measurement | `internal/tui/components/chat/editor.go` rebuilds Bubble Tea's wrapped-line cache in a full-height probe before sizing the live editor. |
| Container rendering | `internal/tui/layout/container.go` preserves a child render that grows beyond a stale one-row allocation. |
| Regression coverage | `internal/tui/components/chat/editor_growth_test.go` covers the exact long-prompt boundary. |
| Arch packaging | `scripts/build-arch.sh` writes and validates an intermediate tar before compression, preventing truncated package output. |
