# Gorilla OpenCode v0.1.43 — You can now see what the agent did, understand why, and copy the whole session out

**Date:** 2026-07-28
**Previous version:** v0.1.42

---
## Why This Release Exists
Three things came up in normal use and turned out to share a root. Warning messages printed themselves over the interface and would not go away. The saved conversation was close to useless if you needed to work out what had actually happened — no times, no record of what the tools did, no sign of the model's thinking. And there was no way to select five hours of a session and paste it into a text editor. Chasing those three uncovered two more serious problems nobody had noticed: on a brand-new install, saving one setting silently threw away the one you saved before it, and every duration the program displayed was a thousand times too small.

## What You'll Actually Notice

**Warning messages**
- BEFORE: Duplicate-endpoint warnings appeared on your terminal at launch and stayed there for the whole session, unclearable. Measured: 2 lines.
- AFTER: 0 lines. They go to the log where they belong.
- Affects: everyone

**Saving settings on a fresh install**
- BEFORE: Paste an API key, then add a local server, and the key was gone. Silently.
- AFTER: Each save keeps the ones before it.
- Affects: some users

**Saved conversations (/export)**
- BEFORE: No times, no tool results, no thinking. You could see every decision the agent made and not one outcome.
- AFTER: Every message timestamped and offset from the session start, every tool call with the result that came back, the model's reasoning, and a summary of failures at the top.
- Affects: everyone

**The model's thinking**
- BEFORE: Thrown away for every provider except Anthropic — while we were still paying the model to produce it.
- AFTER: Captured and stored, so it appears on screen and in the export.
- Affects: everyone

**How long a reply took**
- BEFORE: A 45-second reply displayed as 45ms. Every model looked instant.
- AFTER: 45s.
- Affects: everyone

**Copying a whole session**
- BEFORE: Impossible. Ctrl+A selected nothing.
- AFTER: Run with --plain and the whole conversation is ordinary terminal text you can select, copy and search.
- Affects: everyone

**Managing your AI connections**
- BEFORE: A connection saved under your own name did not appear in the list at all, and none could be removed without editing a file by hand.
- AFTER: Your connections are listed, d removes one after confirming, and a key pasted without its nvapi- prefix is repaired with an explanation.
- Affects: some users

## Decisions & Why

**Asking the model to think out loud is OFF until you turn it on** — It makes the model write several times more than the answer alone, which uses more of your allowance or more of your CPU. Something that spends more should be chosen, not inherited from a default you never saw. (benefits: anyone paying per token or running a model locally; tradeoff: You have to switch it on to get the explanations, and we ask you once at first run rather than assuming.)

**Only one of the four new switches is labelled as costing anything** — Showing a tool call costs nothing — the call already happened and was already paid for. Bundling them together would suggest that hiding tool calls saves money, and you would lose the record for no saving at all. (benefits: everyone; tradeoff: Four switches to read instead of one.)

**We quote no price anywhere** — We hold no published rate for any of the local models, and a free NVIDIA tier or a model on your own machine bills no money at all. 'This will cost you X' would be false on this very machine, and a warning that can be caught out once teaches you to ignore all the others. (benefits: everyone; tradeoff: You get a description of what is consumed — allowance, CPU, heat, waiting — rather than a number.)

**A separate --plain mode rather than rebuilding the main interface** — The normal interface draws on the terminal's alternate screen, which has no scrollback at all. That is how alternate screens work; no amount of work inside the interface could make Ctrl+A select anything. A separate mode gives you the capability immediately and cannot break the interface you already use. (benefits: anyone who needs to keep or share what happened; tradeoff: Plain mode has fewer commands. Changing model or editing settings still needs the full interface.)

**Permission requests in plain mode are asked, not auto-approved** — Silently handing an interactive agent your shell is not a decision to make on somebody's behalf. (benefits: everyone; tradeoff: You answer y/n during a turn. If input closes mid-question we deny rather than assume you agreed.)

## Deliberately Not Done

- **Rebuilding the main interface so it too can be copied** — It is the better end state and would remove the need for a second mode, but it means moving 21 pop-up sites across 15 different dialogs and about 2,700 lines of layout code that all assume they own the whole screen. That is its own project, and shipping it half-finished would be worse than shipping nothing.
- **A counter showing exactly how many reasoning tokens you spent** — We asked NVIDIA's endpoint directly. It reports only prompt, completion and total tokens — there is no reasoning breakdown to read. Building a counter for a number the provider never sends would be dead code. Instead the export reports how much reasoning was actually captured, with an estimate clearly marked as an estimate.
- **A money figure in the cost warning** — We have no price data for these models and the ones in use here are free. See above.

## Privacy & Security
Exported transcripts are now written readable only by you (0600). They were world-readable before, which mattered because a transcript can contain file contents and command output. Nothing new is sent anywhere: the reasoning we now capture is stored in your local session database exactly like the rest of the conversation. Plain mode asks before letting a tool act rather than approving everything automatically. One change increases what leaves your machine and only if you choose it: asking the model to think out loud sends an extra parameter with your request and receives more text back.

## Risks, Backup & Recovery

- **Backup needed:** No. Your existing config and sessions are read as they are, and the new timestamped export works on conversations you already have.
- **Install time:** Under a minute.
- **Restart required:** Yes. A running copy keeps the version it started with, and it also holds your old settings in memory — if it writes them back it will undo changes made elsewhere. Quit it before or after installing.
- **Rollback:** Download the previous .deb from the v0.1.42 release and install it with sudo dpkg -i. Nothing in this version changes the format of your saved data, so going back does not lose anything.

## How To Install

**Step 1:** Quit any running copy first.
```
pkill -f gorilla-opencode
```
✓ Success looks like: No output, and no gorilla-opencode in your process list.

**Step 2:** Download the .deb and its checksum file from the release page, then check the download is intact.
```
sha256sum -c gorilla-opencode_0.1.43_amd64.deb.sha256
```
✓ Success looks like: gorilla-opencode_0.1.43_amd64.deb: OK

**Step 3:** Install it with the package manager.
```
sudo dpkg -i gorilla-opencode_0.1.43_amd64.deb
```
✓ Success looks like: Setting up gorilla-opencode (0.1.43)

**Step 4:** Confirm the program and the package manager agree on the version. If they disagree, something was copied by hand rather than installed.
```

```
✓ Success looks like: v0.1.43, and 0.1.43 in the package line

**Step 5:** Try the new mode.
```
gorilla-opencode --plain
```
✓ Success looks like: A plain prompt you can select and copy, with a line telling you what is being shown and what it costs.

## What's Still Broken

- **The main interface still cannot be selected and copied** (anyone not using --plain) — workaround: Use --plain, or /export for a complete written record. — status: Open. It needs a large rebuild of the interface, planned separately.
- **No exact count of reasoning tokens spent** (everyone on NVIDIA NIM) — workaround: The export reports how much reasoning was captured, with an estimate marked as such. — status: Blocked by the provider, which does not report the number.
- **Interactive keypresses cannot be tested automatically here** (nobody directly; it affects how thoroughly we can check changes before you see them) — workaround: Layout and logic are tested without a terminal; the parts that need a human are named as such. — status: Known limitation of the development environment.
- **Four duplicate NVIDIA entries may still be in an older config** (anyone who re-pasted the same key several times) — workaround: Open /connect, select the ones you do not want and press d. — status: Fixed for the future; existing entries are yours to tidy.

## Common Questions

**Q: Will this cost me more money?**
A: Not unless you switch on 'ask the model to think out loud'. It is off by default and we explain what it costs before you turn it on. The other three new switches are free — they only change what you are shown.

**Q: Why does the warning not tell me how much it costs in pounds or dollars?**
A: Because we do not know, and pretending would be worse. We hold no published price for the models set up here, and the two you are most likely using — a free NVIDIA tier and a model on your own machine — cost no money at all. So we describe what is actually used up instead.

**Q: Do I have to use --plain now?**
A: No. The normal interface is unchanged and gets the new timestamps and reasoning display. Use --plain when you specifically want to select and copy the session.

**Q: Will my old conversations get timestamps?**
A: Yes. The times were being recorded all along, they were just never shown. Export an old session and you will see them.

**Q: I exported a session before and it was useless. Is that fixed?**
A: Yes, and the fix applies to sessions you already have. You will now get the time of every message, every tool the agent ran with the result that came back, and the model's reasoning for anything recorded after this update.

**Q: Something looks wrong — how do I work out what happened?**
A: Run /export. You get a timestamped record of every message, every tool call and result including the failures, and a summary at the top of anything that ended abnormally.

## Bottom Line
This release is about being able to answer the question 'what just happened, and why'. Before it, a saved session told you what the agent decided but never what came of it, showed no times at all, and never showed the model's reasoning because we were discarding it. All three are fixed, and the fixes work on conversations you already have. You can also now run with --plain and copy an entire session out with your terminal's own keys, which was simply not possible before. Along the way we found two problems nobody had reported: on a fresh install, saving one setting quietly deleted the one before it, and every duration displayed was a thousand times too small. Both are fixed. The one thing that can cost you more — asking the model to think out loud — is off until you choose it, and we tell you what it uses rather than inventing a price we cannot know. The main interface still cannot be copied from; that needs a large rebuild we have deliberately not rushed.

## Subsystem Changes

**NETWORK:** Outbound requests to OpenAI-compatible endpoints gain chat_template_kwargs={thinking:true} ONLY when extras-reasoning-generate is enabled, which is off by default. On a 4xx naming the parameter, or a 4xx/422 with unknown-field language, the parameter is dropped for that model and the request retried once. Rate limits, auth failures and generic 400s are explicitly NOT treated as parameter rejections, so an unrelated blip cannot silently disable reasoning.

**STORAGE:** config.json gains `extras` (map[string]bool) and `extrasChoiceMade` (bool), both omitempty. No migration: absent keys fall back to registry defaults. Message storage unchanged — ReasoningContent was already a persisted part type, it was simply never populated outside Anthropic.

**TELEMETRY:** No changes. No telemetry is collected or transmitted. Captured reasoning is stored only in the local session database.

**OTHER:** Exported transcripts written 0600, previously 0644. Rationale: a transcript embeds file contents and command output.

## Security Posture
No CVEs addressed and no dependency changes. Attack surface: unchanged, with two reductions. Exported transcripts move from 0644 to 0600. Plain mode prompts for tool permission rather than calling AutoApproveSession as the -p path does, and denies when stdin closes mid-question rather than defaulting to grant. One addition sends more data outbound, opt-in and off by default: the thinking parameter. During development a live API key was read three times for measurement; all copies were shredded and the scratchpad verified clean by pattern search. A test also wrote a stray key into the developer's real config — removed, backed up, and the class of failure closed by configtest.Isolate.

## Known Issues & Deferred Work

- [medium] The TUI still renders in the alternate screen, so its history cannot be selected or copied. Converting it means rehoming 21 PlaceOverlay sites across 15 dialog surfaces plus ~1,430 lines of chat rendering and ~1,300 of layout machinery that assume a full-screen frame. --plain is the interim answer.
- [low] No exact reasoning-token count. Measured: NIM's usage object carries prompt_tokens, completion_tokens and total_tokens only, with no completion_tokens_details.reasoning_tokens. The export reports captured characters plus a 4-chars/token estimate, explicitly labelled.
- [low] Only NVIDIA NIM and Gemini reasoning capture were verified against live endpoints. OpenRouter's `reasoning` field and the `thinking` variant are covered by unit tests against captured shapes but not by a live call.
- [low] extras-reasoning-show/-toolcalls-show gate the TUI and plain renderers but are not consulted by the export renderer, which always includes everything. Intentional for a forensic record, but it means the switches are display-only.
- [low] Interactive keystroke sequences cannot be driven in this development environment; a minimal Bubble Tea program also fails to receive piped-PTY input, so it is environmental.
- [low] Duplicate local-endpoint rows in an existing config are ignored and logged but not auto-removed; they are user data. /connect can now delete them.
