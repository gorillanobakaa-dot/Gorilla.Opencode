# gorilla-opencode v0.1.80 — release notes

Released 2026-08-11. One feature, live-tested end-to-end before shipping.

## Plain-language version

**`/usage` now draws your quota as a real meter, with bananas.**

Before, checking your free weekly allowance printed one line:
`Claude and GPT models: 96%`. Ninety-six percent of what? Left, or spent? The
program knew; you had to guess. Guessing wrong means either panicking over a
full tank or burning a week you thought you still had.

Now `/usage` prints a panel you can read at a glance:

- **A coloured bar for each model group.** The bar is painted like a
  thermometer: red at the left end, green at the right. As your week burns
  down, the bar shrinks from the green end — so the tip of the bar is always
  the colour of what you have left. Full and green means relax; a short red
  stub means the week is nearly spent.
- **Both numbers in words**, so there is nothing to decode: "75% left, 25%
  used · resets in 2d".
- **Bananas.** This is Gorilla OpenCode. Above half a tank you get
  "🍌🍌🍌 Loaded up on bananas... let's go nuts." As the meter drops the
  bananas thin out, and at zero the gorilla appears: "🦍 No more bananas for
  today." The bananas carry the mood; the exact numbers are always printed
  right next to them.
- **If you pay for DeepSeek or OpenRouter, your money shows here too.**
  DeepSeek reports how much balance you have, so the panel shows the amount.
  OpenRouter reports credits bought and credits used, so it gets a bar like
  the weekly quota. If you have an OpenRouter key but never bought credits,
  it says exactly that — "no credits purchased — free models only" — instead
  of pretending an empty wallet is an empty tank.
- **When a balance check fails, the panel says so.** A provider that errors
  shows "Couldn't check the balance: …" rather than quietly vanishing —
  because a missing section would read as "no key configured", which would be
  a lie.

The one-line summary that appears by itself at the start of each session is
unchanged. The full panel only appears when you ask for it.

## Technical

New package `internal/quota`: balance readings for providers with a genuine
balance endpoint on an ordinary API key — DeepSeek (`GET /user/balance`,
amounts are strings on the wire) and OpenRouter (`GET /api/v1/credits`).
Readings normalise to `{Text, Fraction, FreeTier, Err}`; `Fraction = -1`
means "no denominator exists", and the renderer then shows the amount without
inventing a percentage. Fetch errors fold into the reading (`Err`) so the
panel renders them; HTTP error bodies are never echoed (an auth error body
can contain the key). Providers with only rate-limit headers (Anthropic,
OpenAI, xAI, Groq) are deliberately not metered.

New renderer `internal/tui/quota_panel.go`: pure function of
`(*auth.QuotaSummary, account, []quota.Reading, width, now)` — no network, no
wall clock, headlessly testable. Bar cells have fixed colours
(`hue = 120° × position`, HSV s=v=1, two-sextant conversion since blue is
always 0); the fill length is the remaining fraction, so the tip cell's
colour equals the level's colour. Thresholds for the banana ladder: ≥50%,
≥⅓, ≥20%, >0, 0. Text wraps via reflow `wordwrap` (lipgloss `.Width()` pads
with trailing spaces that copy out of the terminal), with hanging indents on
continuation lines. Emoji appear only in the scrollback panel, never in the
footer line — the footer lives in the inline frame, where any width the
terminal disagrees with strands debris (see the trap list in CLAUDE.md).

`/usage` (and only `/usage` — not the quiet session-start fetch) now also
queries configured provider balances; a user with no Antigravity sign-in but
a DeepSeek/OpenRouter key still gets a panel.

**Found by driving the real binary, not by the test suite:** agy 1.1.11
renamed the quota bucket's `displayName` to "Weekly Limit Remaining" (the
1.1.10 capture our fixture came from said "Weekly Limit"), so the panel
printed "Weekly Limit Remaining Remaining". Every headless test passed
against the stale fixture. The renderer now appends the word only when the
wire didn't, the fixture carries both shapes, and a regression test pins it.
The lesson — one live drive of the built binary before calling UI work done —
is recorded in CLAUDE.md, along with the GNU-screen method that makes such a
drive possible from an agent shell (`stuff` with `\r` for Enter,
`hardcopy -h` for scrollback).

## Claim sourcing

- Antigravity panel, live: **verified** (driven end-to-end via GNU screen
  against the live `retrieveUserQuotaSummary`, twice — before and after the
  displayName fix).
- OpenRouter free-tier response: **verified live** with a real key
  (total_credits 0 path).
- OpenRouter paid response shape, DeepSeek balance shape: **model_inference**
  from vendor API documentation — no paid OpenRouter account or DeepSeek key
  was available. Flagged in-source; if a section renders blank with a valid
  key, capture the live body and fix the struct tags.
- Colour values: verified against Python `colorsys` reference values in
  `TestQuotaColorGradientGreenToRed`.
- Width invariant (no line wider than the terminal, emoji counted as two
  columns): asserted per line at widths 80/60/40/25.
