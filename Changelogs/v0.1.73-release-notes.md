# Gorilla OpenCode v0.1.73 — the token sieve: 92% less sent, and a way to find the free copy

**Plain-language version below every technical section. Read whichever suits you.**

---

## Why This Release Exists

An API can only bill you for what you send it.

That sentence is the whole of this release. Everything below is its
consequences, measured.

The web-fetching tool this project inherited did what nearly every such tool
does: it fetched a page and handed the entire thing to the language model.
Navigation, cookie banner, sidebar, footer, tracking scripts, the analytics
payload — all of it, billed by the token, and then **billed again on every
subsequent turn of the conversation**, because a model re-reads its whole
context each time it replies.

We measured what that costs. Eight real pages:

| page | tokens sent before | tokens sent now | cut |
|---|---|---|---|
| GitHub file page | 62,083 | 885 | 99% |
| MDN documentation page | 44,219 | 1,568 | 96% |
| A large search page | 34,759 | 3,931 | 89% |
| Wikipedia article | 25,595 | 3,928 | 85% |
| arXiv abstract page | 10,744 | 1,769 | 84% |
| **total across all eight** | **179,100** | **13,781** | **92%** |

Ninety-two percent of what was being sent — and paid for — was furniture.

**Plain-language version:** When you asked the assistant to read a web page, it
used to send the *entire* page to the AI service: the menus, the advertising
scripts, the cookie banner, the footer. You were charged for every word of it,
and charged again each time the conversation continued. We measured it on eight
real pages. Ninety-two percent of what you were paying for was not the article.

## Who This Is Actually For

This is not a performance optimisation. It is a question of who can use the tool
at all.

This project is written for people who are not the intended customer of the AI
industry. A household of two parents and two children living on a dollar a day
cannot absorb two dollars a month. There is no version of "it's only a few cents
per query" that survives contact with that arithmetic. For that family, a
badly-designed fetch tool is not inefficient — it is a locked door.

Send few enough tokens and something changes in kind rather than degree: **you
fit inside the free tiers permanently.** A provider offering a fixed number of
free requests per day is generous if each request is small and worthless if each
request carries a web page. At a nominal one-million-token daily allowance, the
difference we measured is between **16 GitHub pages a day and 2,754**.

Staying small is what makes the tool free forever. Free forever is what makes it
usable by someone who cannot enter a card number.

We want to be accurate about the target rather than righteous about it. Nobody
set out to overcharge a child in a village. The incentive simply runs one way:
a service **paid by the token** has no reason to build the dials whose purpose
is to send fewer of them, and the people writing these tools work on fast
connections with corporate cards, where 62,000 tokens to read a README is
invisible. Some providers — Google among them — do offer real free tiers, and
that deserves saying. But a free tier you exhaust in sixteen requests is a
technicality, not access.

So: nobody is coming to build this. That is the entire reason this repository
exists.

**Plain-language version:** Why does a coding tool care so much about a few
cents? Because for some of the people this is built for, a few cents is the
difference between using it and not. If a family lives on a dollar a day, two
dollars a month is not a rounding error. And if you send small enough requests,
you never pay anything at all — you stay inside the free allowances forever. We
are not accusing anyone of malice. The companies building these tools work on
fast internet with company credit cards, where waste is invisible. It just means
nobody else was going to fix this for you.

## 1 — The source ladder: ask for the document, not the page around it

Every fetch now walks down a ladder and stops at the first rung that answers,
and **reports which rung it used**.

| rung | what it is |
|---|---|
| 0 | A structured API — arXiv export, NCBI E-utilities, Wikipedia REST |
| 1 | The source document — `Accept: text/markdown`, `raw.githubusercontent.com`, a `.md` companion |
| 2 | HTML converted locally, with nav, scripts, forms and footers stripped first |
| 3 | Refuse, and say why |

New in this release: `arxiv.org/abs/…` → the export API,
`pubmed.ncbi.nlm.nih.gov/…` → E-utilities XML, `en.wikipedia.org/wiki/…` → the
REST summary (25,595 tokens → 600), joining the `github.com/…/blob/…` →
`raw.githubusercontent.com` rewrite from v0.1.72.

The reporting matters as much as the saving. A model that read a reconstruction
should know it read a reconstruction, so it can weigh its own confidence.

**Plain-language version:** Before grabbing a whole web page, the tool now asks
whether a clean version exists — many sites publish one — and takes shortcuts it
knows about, like fetching a GitHub file directly instead of the page that
displays it. It also tells the assistant which route it took, so the assistant
knows whether it read the real document or a cleaned-up copy.

## 2 — `web_search`: finding sources, and finding the *free* copy

The agent previously had no way to search at all. Asked for papers, it
hand-constructed query URLs for publisher sites from memory, collected 403s, and
in one observed case invented a citation table rather than report the failure.

There are now seven sources, none requiring an API key:

| source | what it searches |
|---|---|
| `scholar` | OpenAlex — all disciplines, ~250M works |
| `medical` | Europe PMC — indexes MEDLINE/PubMed |
| `crossref` | Crossref — DOI metadata across publishers |
| `openaccess` | **Unpaywall** by DOI, **DOAJ** by keyword |
| `books` | Project Gutenberg (full text), Open Library |
| `reference` | Wikipedia |
| `all` | scholar + medical + crossref, de-duplicated |

**Every scholar search now flags free legal copies inline.** OpenAlex was already
telling us where an open-access version lives and we were discarding the field.
Measured on one query: **7 of 10 results** carry a `FREE LEGAL FULL TEXT` link.

`openaccess` is the one to reach for when a user hits a paywall. Give it a DOI
and Unpaywall answers the only question that matters at that moment: *is there a
legal free copy of this, and where?*

**Plain-language version:** The assistant can now search for papers and books
instead of guessing web addresses. More importantly, when it finds a paper
locked behind a paywall, it checks whether a **legal, free copy** exists
elsewhere — very often it does, posted by the authors or their university — and
gives you that link. Nobody should be told to pay $40 for a paper that is free
on the next page.

## 3 — What is *not* available, said out loud

There is **no general web search** (Google, Bing, DuckDuckGo) in this release.
We tested the keyless options and rejected all of them: DuckDuckGo's HTML
endpoint answers `200` with a block page on every attempt, public SearxNG
instances returned 403s and 429s, Marginalia's public API returned nothing.

Shipping any of those would have been worse than shipping nothing, because the
model cannot tell a block page from a result and will summarise it in good
faith. The tool description now states the gap plainly, so a model without a URL
**asks the user for one instead of inventing a source.**

**Plain-language version:** The assistant cannot do a normal Google-style web
search. Free search engines either block automated access or return nothing
usable, and one that silently returns a "you look like a robot" page would be
worse than none — the assistant would read it and summarise it as if it were
real. So it now says clearly when it cannot search, and asks you for a link.

## 4 — TextRank: local summarising for long documents

For genuinely long text, an extractive summariser now runs **on your machine**,
in the binary, with no Python and no dependencies. Two rules are enforced in
code rather than written as advice:

- **It refuses on short text** (under 8,000 characters). An abstract is ~330
  tokens; compressing it saves nothing and can delete the finding.
- **Every summary declares its compression ratio and that it is extractive**,
  and warns that centrality is not importance — a paper's caveats, limitations
  and negative results are frequently the *least* central sentences and the
  first to be cut.

**Plain-language version:** Very long documents are shortened on your own
computer before anything is sent, using mathematics rather than AI — the same
family of algorithm behind the original Google PageRank, applied to sentences.
It always tells you how much it cut and warns that the parts it dropped may
include the paper's own caveats. It refuses to shorten anything already short,
because that would risk losing the point to save nothing.

## 5 — A 26% smaller download

The binary now builds with debug symbols stripped: **66.1 MB → 48.6 MB**, and
the package shrinks accordingly. On the single-digit-KB/s connections this
project is built for, that is roughly **forty minutes of download time returned
to the user.**

Our own philosophy applied to our own artefact: it is not coherent to tell
someone not to send a 42 KB page and then hand them a 32 MB install.

## Decisions & Why

**Choosing the source beats cleaning the page.** In the eight-page measurement,
the clean sources show "0% cut" — because there was nothing left to strip. The
saving had already happened when the source was chosen.

**A block page must never be returned as a result.** Any future general-web
backend must sit behind an API key and fail loudly.

**TextRank in Go, not Python.** The tempting pipeline needed `xmllint`, `pup`,
`html2text` and `sumy`. On 2026-08-07 none of those four were installed on this
project's own development machine, and on a 2 GB laptop a Python numeric stack
is a larger install than this entire application. About 150 lines of Go ships
inside a binary that is already there.

**We did not build a shadow-library backend.** `web_fetch` reaches any URL a
user types — that is their decision. Making infringement a *feature of the
distributed artefact* is a different thing, and the legal open-access route
covers papers very well. It does not cover current commercial textbooks, and we
would rather say so than pretend the gap is closed.

## Risks, Backup & Recovery

- **Stricter SSRF blocking** (from v0.1.72) refuses loopback, link-local,
  private-LAN and multicast addresses including via redirect. A local
  development server on `127.0.0.1` cannot be fetched by the agent. Deliberate.
- **`web_fetch` is the tool's name** since v0.1.72; saved prompts referring to
  `fetch` need updating.
- **The prompt grew** by ~68 tokens per coder turn across v0.1.72 and v0.1.73,
  buying the elimination of "I can't reach the internet" and of invented
  citations. Both lines are switchable off in `/context`.
- Downgrade: `sudo dpkg -i gorilla-opencode_0.1.72_amd64.deb`.

## What Was Not Verified

- **No live fetch over a genuinely slow link.** All measurements were taken on a
  normal connection and are byte counts, not timings.
- **Hit rates are unmeasured** for `Accept: text/markdown` and the `.md`
  companion — cheap when they miss, but no data yet on how often they hit.
- ~~TextRank not exercised end to end~~ **Verified 2026-08-07** on a 169,504-character
  public-domain text: ~42,376 tokens reduced to ~828 (12 of 1,300 sentences, 2.0%),
  and it correctly refused a short input. It has NOT been driven through a live
  agent turn.
- **The prompt lines' effect on model behaviour is reasoning, not evidence.** The
  pre-registered experiment at `system-prompts/EXPERIMENT-PREREG-2026-08-04.md`
  has still not been run.
- **Token counts are byte/4 estimates**, not tokeniser output. Good to roughly
  ±15%; the 92% ratio is unaffected since both sides use the same estimate.

## Bottom Line

Ninety-two percent less sent to the meter. Free legal copies surfaced on seven
of ten search results. A tool that says when it cannot search instead of
inventing a source. A summariser that admits what it dropped. And a download
forty minutes shorter.

None of it is clever. All of it is the consequence of one sentence: *an API can
only bill you for what you send it* — taken seriously by people who had a reason
to.
