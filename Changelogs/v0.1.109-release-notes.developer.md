# v0.1.109 — the cold-start toast stopped blaming healthy links, and /context works mid-turn

> Session record generated 2026-08-20

---

## Problem Being Solved

v0.1.108 disabled streaming on the austere and constrained profiles (27x less downlink, identical token accounting). The TUI's cold-start toast is keyed to streaming: shouldColdStartWarn fires when a pre-token phase ('Thinking...'/'Generating...') stays quiet past coldStartHint = 12s. With streaming on, the first token changes the phase within a second or two and it never fires. With streaming off nothing arrives until the reply is complete, so the phase is quiet for the whole generation and the toast fired every turn on a fast link with a healthy provider — observed twice in one turn. Its wording is a diagnosis ('a quiet endpoint is usually warming up, not stuck') and it was the wrong one.

Separately: a model looping on tool calls left the user unable to change anything until it finished. controlCommands existed for this, added 2026-08-14, but covered only helper management.

## Approach Taken

Split the toast by mode instead of suppressing it. coldStartMessage() returns the original wording when config.StreamRepliesEnabled(), and a different sentence when not: the quiet is expected, the reply arrives in one piece, that is 27x less data, this is not a stalled connection, /connection switches back. The footer gets a short suffix from arrivesWholeSuffix(); the full sentence goes to the transcript via util.ReportInfoEcho — the split this file already uses because the footer is one row and lipgloss wraps.

For the lockout, extended controlCommands by exactly one command family, chosen against the list's own stated criterion.

## Before

coldStartMessage did not exist; the sentence was inline in Update. workingLabel returned phase plus counter with no mode awareness. controlCommands = {tasks, task, agents, kill, help, commands}. The busy warning mentioned only /tasks and did not mention esc.

## After

Two messages selected by StreamRepliesEnabled(). Footer carries ' (one piece)' on non-streaming pre-token phases, worst case 31 bytes against the documented 32-byte cap. controlCommands additionally holds context/loadout/tokens. Busy warning names esc and the commands that still work. config.UseConnProfileForTest added so a profile-switching test restores state.

## Known Alternatives

Suppressing the toast entirely when not streaming: rejected — the user asked for both, so a long wait still says something instead of nothing. Reverting non-streaming: rejected, it would discard the release's largest measured saving for a wording bug. Adding /model to the allowlist: TRIED AND REVERTED, see tried_and_abandoned.

## Decisions Made

- 📄 **Two messages, not suppression** — Owner's instruction: keep the old message for genuinely slow links, and separately tell the user that on this setting silence is expected and the whole message will arrive at once
- 📄 **Short in the footer, full in the transcript** — The footer is FooterReservedRows (1) tall and lipgloss WRAPS instead of truncates; the explanation lives in a toast
- 📄 **/context allowed while busy** — RebuildProvider defers via pendingRebuild and drains on completion, so a loadout change mid-turn is recorded and applied at the end
- 📄 **/model stays gated** — Choosing calls CoderAgent.Update() and swaps the provider under an in-flight request; the criterion is the command's consequence, not its dispatch
- 🤖 **/connection stays gated** — It hands the terminal to a full-screen picker via tea.Exec; doing that mid-stream corrupts the display

## Tried and Abandoned

- **Adding /model and /models to controlCommands** — TestSendingCommandsAreStillGated refused it and was right: opening the dialog is inert but choosing calls CoderAgent.Update(), swapping the provider under a live request. Removed the same day
- **Footer suffix ' - whole answer at once' (23 bytes)** — Pushed the worst-case label to 42 bytes against working_label_test's documented 32-byte cap; it would have wrapped into a second row and corrupted the scrollback erase
- **A middot separator in the footer suffix** — TestNothingThatDrawsUsesAmbiguousWidthCharacters rejected it — U+00B7 is East Asian Ambiguous, measured as 1 column and drawn as 2 in a CJK terminal
- **Calling config.SetConnProfile directly in a new test** — It writes a package variable behind a sync.Once, so it changed what every later test in the binary observed; working_label_test began failing an assertion it had always passed
