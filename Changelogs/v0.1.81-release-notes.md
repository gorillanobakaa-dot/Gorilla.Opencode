# gorilla-opencode v0.1.81 — release notes

Released 2026-08-12. Two fronts: the model picker learned to answer questions
("which free coding model?", "who bills me for this?", "what IS this model?"),
and the banana meter learned to speak up while you work instead of waiting to
be asked.

## Plain-language version

**Find a model by typing what you want.** The catalogue is past 270 models on
OpenRouter alone, and scrolling it row by row was a reading assignment. Press
`/` in the model picker and type words — `free coding`, `advanced reasoning`,
`research` — and the list narrows to models whose name **or description**
contains them, across every provider you have connected at once. The counter
updates as you type; esc puts you back exactly where you were.

**Press tab on any model for the full story.** One row could never hold enough
to choose by, so every model now has a full page: what it is (the complete
description, not a stub), the exact prices including cached reads, the context
window and output limit, what it can do (tools, reasoning, images), whether
you bookmarked it — and the one fact no row could show:

**Which of YOUR keys pays for it.** A row reading "MoonshotAI: Kimi K2" looks
like it comes from Moonshot, but the request is billed to whichever key you
connected. People on free tiers rotate several keys to spread quota, and until
now the picker could not say which one was live. Now the column header says
it: *"every request below is billed to your openrouter key sk-or-…#8f46 (73
chars)"*. The fingerprint tells your keys apart at a glance and can never
reveal the key — picker screens end up in screenshots, and screenshots end up
in chats.

**Full descriptions, and an honest apology where none exists.** OpenRouter's
own catalogue API cuts every description off around 215 characters — 354 of
their 406 models arrive ending in "...". The release build now fetches each
model's public page for the complete text: 264 of 279 models carry their whole
description. For the 15 where OpenRouter publishes nothing more anywhere, the
detail page says exactly that: *"sorry lads — not our fault: that is ALL
OpenRouter provides as a description for this model."* A cut that isn't
labelled looks like our bug — it was reported as exactly that, twice.

**The gorilla now warns you as the bananas run out, not just when you ask.**
The banana ladder grew from five rungs to nine — below 20% it splits into
escalating bulletins ("This is not a drill. The barrel has a bottom and I can
see it." → "Rationing mode: sniff the banana, don't eat it." → "Last banana
spotted. Nobody make any sudden prompts." → "Zero bananas. Even the peel is
gone.") — and after each response the meter is re-checked (at most once every
30 seconds). Cross a rung mid-session and the gorilla announces it right
then, in the scrollback with the emoji and on the footer without them. A long
tool-heavy session used to burn through half a week's quota invisibly between
`/usage` calls; now the crossing is called out while it happens. The weekly
reset stays silent — good news doesn't need an alarm.

**Smaller fixes:** the picker no longer overflows narrow terminals (its old
62-column minimum clipped anything narrower); an empty search result reads
"0/0" instead of the nonsensical "1/0"; the picker fits itself to the window
in both directions and cuts long text with a visible marker, never silently.

## Technical

**Picker search (`internal/tui/components/dialog/models.go`):** `/` snapshots
every enabled provider's models as a search domain (bookmarks column skipped —
same models, tagged twice). Space-separated terms AND together over name,
description, full detail text, provider id and model id. While searching,
arrows/enter/tab/esc keep their meanings; every printable character — including
space and the j/k/h/l/b navigation letters — is text. Results carry a
`[connection]` tag (local-endpoint name or home provider), per-provider ranks
are suppressed (cross-provider "1." three times would imply an ordering nobody
made), esc restores column, selection and scroll position. Selection resets
search/detail state — the dialog object is reused between opens.

**Detail page:** tab opens a full-frame page rendered from the `Model` struct
plus `connectionFor()` provenance; space bookmarks from inside it (keyed off
the detailed model's id, not the list selection, which a bookmark-triggered
column rebuild can move), enter selects, tab/esc back out. Body wraps to the
window; overflow is cut with a visible marker. Frame width and height are both
clamped (the marching-footer invariant: no line wider than the terminal, no
frame taller than the window at ≥24 rows).

**Key fingerprints (`internal/config`):** `ProviderKeyFingerprint` renders
`prefix…#hhhh (N chars[, from env])` — first six characters (vendor
boilerplate), first two bytes of SHA-256 (tells rotated keys apart, useless
for recovery), length, and whether the key came from the environment rather
than the config file. OAuth providers return login descriptions instead;
Bedrock/Vertex sentinels are named as ambient credentials. Mutation-tested:
making it return the raw key fails two suites.

**Full descriptions (`cmd/openrouter-models`, `internal/llm/models`):**
`Model.Detail` carries the long text; the generator fetches each model's
public page (4 workers, one retry, ~280 pages, dev machine only) and extracts
the description from the page payload — anchored on the API text as a prefix,
longest match wins, double-escaped `\n` decoded. `DetailForPicker` caps at
2400 chars and appends the apology constant only when the trailing "..." is
upstream's (detected before our cap, so we can never blame OpenRouter for our
own cut). Runtime `models refresh` NEVER scrapes pages (~85 MB — hours on a
metered link); it keeps the fuller bundled text via `PreferFullerDetail`,
which strips the apology before its prefix comparison — left in place, the
apology's trailing ")" would hand the win to the truncated copy with a false
apology attached. Catalogue cache schema bumped 5→7 (Detail added; merge rule
added); older caches are discarded with a message naming the fix.

**Catalogue regenerated 2026-08-12:** 279 tool-capable models (was 274), six
added, one retired upstream (`openai/gpt-5.3-chat`), prices refreshed — e.g.
DeepSeek V4 Pro moved from $0.43/$0.87 to $0.63/$1.26 per 1M. The generated
file is the authority on every number; its header records the generation date.
Some one-line labels changed because classification now reads the full text —
e.g. Qwen3-VL was "research/admin work" off the truncated text and is now
correctly flagged as a vision/image model (the word "OCR" lives past
character 215).

**Banana ladder (`internal/tui/quota_panel.go`, `tui.go`):** the ladder is a
single `bananaTier` switch (8..0) — the alert system compares tiers between
readings, so the thresholds live in exactly one place. `bananaAlerts` returns
one announcement per group whose tier DROPPED; rises (weekly reset) are
silent, and first sight only seeds the baseline. Post-response checks are
throttled to one per 30s and fail silent — an alert system that nags about
its own plumbing is worse than none. Footer echo goes through
`stripBananaEmoji` (supplementary-plane pictographs removed): emoji live only
in the scrollback panel, never in the inline frame, where a width the
terminal disagrees with strands debris.

## Claim sourcing

- Picker search, detail page, provenance line, selection end-to-end:
  **verified live** — the real binary driven via GNU screen (search `free
  coding` → 11 tagged matches; tab → detail; enter → footer switched model),
  plus a 190×50 headless render showing the full 1.2K-character Qwen3-VL text
  ending at its real final sentence.
- Key fingerprint cannot leak: **verified by mutation** — a build that
  returns the raw key fails `TestKeyFingerprintNeverContainsTheKey` and
  `TestDetailPageNeverShowsTheAPIKey`.
- OpenRouter truncates at the source: **measured 2026-08-12** — 354 of 406
  list-API descriptions end in "..."; the per-model API endpoint returns the
  same cut; for the 15 flagged models the public page was fetched under two
  user agents and carries nothing longer.
- Search filtering, boundary behaviour, width/height invariants, apology
  placement, refresh merge rule: **headless tests**, all mutation-checked or
  asserted against the failure they guard.
- The refresh merge (`PreferFullerDetail`) is **unit-tested only** — no
  end-to-end `models refresh` against the live API was run in this session.
  If a refresh ever shows a detail page shorter than before, that path is
  where to look.
- Banana ladder wording and tier arithmetic: **headless tests**. The live
  crossing alert was exercised on the 0.1.80-era dev builds during the
  screenshot session of 2026-08-11 (see docs/screenshots/gallery); it was
  **not re-driven live** for this release.
- Prices: **copied from OpenRouter's API on 2026-08-12**, not probed against
  live billing.
