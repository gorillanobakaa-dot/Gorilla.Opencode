# Gorilla Opencode v0.1.88 — one search tool, and a dossier you have to arm yourself

Released 17 August 2026, six commits after v0.1.87. Two themes: **searching your
code stops costing you twice**, and **research grows a serious, expensive upper
gear that ships switched off**. Along the way the transcript stopped hiding what
tools did, `/context` stopped lying about which switches were on, and the
packaging scripts stopped being willing to wrap last build's binary in this
build's label.

This is the same document in two registers. The plain-language track assumes no prior
knowledge and omits nothing significant. The developer track is precise enough to audit
and rebuild from. Both end with a claim-source table saying which statements this release
measured and which it inferred — see [PHILOSOPHY.md](../PHILOSOPHY.md) for why.

The measured numbers behind the search change are in
[docs/FIND-TOOL-METRICS.md](../docs/FIND-TOOL-METRICS.md); the research change is
explained in [docs/OSINT-RESEARCH.md](../docs/OSINT-RESEARCH.md) and
[docs/OSINT-DOCTRINE.md](../docs/OSINT-DOCTRINE.md). All three ship inside the
package.

## Plain-language track

### Why This Release Exists

Two things were costing you money you could see and nobody was fixing.

The first was search. Until now, asking the program to find something in your code used three separate tools — `ls`, `glob` and `grep` — and `grep` answered "where is this?" with a list of file paths and nothing else. To actually read anything, the AI then had to open a whole file, which is a second message, and every message re-sends the whole standing context. Measured on this repository: the search answer itself was 16 tokens, the forced follow-up read was 1,829 tokens, and the extra round trip of standing context behind it was about 9,935 tokens. So the old pattern did not cost 16 tokens. It cost roughly ten thousand, over and over, and it is what nearly every AI coding product still ships.

The second was research. The existing `/research` command is fine for ordinary questions. It is not built for the questions where being wrong is expensive, and pretending it was would have been dishonest. So this release adds a separate, heavier command — and because heavier means more money, it ships switched off and warns you in dollars per minute before it runs.

### What You Will Notice

**searching your code**
- Before: Three tools. The search found the file; reading it was a second, much more expensive step.
- After:  One tool called `find` that returns the matching lines with the code around them — 132 tokens, one message, for the same question.
- Affects: everyone

**the program file is bigger, not smaller**
- Before: 51,867,940 bytes.
- After:  52,125,988 bytes — 252 KiB more. At 8 KB/s that is about half a minute of download, once. It buys back the ten-thousand-token retries above, every day, forever.
- Affects: everyone downloading it

**seeing what the AI actually did**
- Before: A conversation that used a tool froze on "Waiting for response…" in the scrollback. The tool call and its result were in the database and never on your screen.
- After:  A tool-using turn is held back until its results exist, then printed whole: the call, its arguments, and what came back.
- Affects: everyone

**the `/context` screen**
- Before: A switched-on feature described itself starting with the word "off:", and the tick box and the words disagreed. A real user reported exactly that on v0.1.87.
- After:  Every row leads with a reverse-video **ON**/**OFF** badge that visibly flips when you press space, "> " marks where you are, and the consequence reads "turn off and:" or "while off:". Rows are sorted alphabetically.
- Affects: everyone

**web search telling the truth about itself**
- Before: The description warned it was "probably not configured" on every single message, even on a machine where search was configured and answering.
- After:  The description is built at startup and says which world it is actually in. Configured says so; unconfigured still refuses honestly.
- Affects: everyone

**four new places to look, none needing an account**
- Before: Not applicable.
- After:  World news from GDELT (refreshed every 15 minutes), World Bank documents, humanitarian data from HDX, and full-text search of SEC company filings. All free, none needing a key or a card.
- Affects: anyone using research or web search

**a new command: `/osint`**
- Before: Not applicable.
- After:  A separate command from `/research`, not a nickname for it. It ships OFF. You arm it by hand in `/context`, where its row reads "Serious OSINT dossier — EXPENSIVE" in bright red. `/osint` on its own opens a full-screen page explaining what it is. `/osint <your question>` opens a gate that shows the burn rate worked out live for the model you are actually using, and lets you pick 4 to 10 helpers and whether they run parallel, one at a time, or supervised.
- Affects: only people who arm it

**models that send `"100"` instead of `100`**
- Before: A tool call carrying a number as text failed outright, and the failed call was still billed.
- After:  Anything that converts to the same integer without losing anything — `100`, `"100"`, `100.0` — is accepted. Genuine nonsense like `"abc"` or `100.5` is still rejected.
- Affects: anyone on smaller or local models

### Deliberately Not Done

- **The old `ls`, `glob` and `grep` were retired, not deleted.** Their source files are renamed to `.go.retired` and still in the tree. Old conversation transcripts still render, and a model that asks for `grep` by name gets an error that teaches it to use `find` instead of a dead end.
- **The `/osint` gate's dollars-per-minute figure is not a measurement.** It rests on three assumptions — steps per helper, tokens out per step, seconds per step — which are printed on the screen right next to the number so you can argue with them. Making it a measurement needs real telemetry from real runs, which does not exist yet.
- **118 paid-only sources are kept in the registry on purpose.** So the tool can say "the definitive source exists, behind a subscription" instead of quietly pretending it does not.
- **The stranded-lines problem an Arch tester reported on v0.1.87 is not fixed.** It could not be reproduced on this machine. Guessing at a fix nobody can verify would be worse than saying so. See below.

### Privacy & Security

The `/osint` dossier is written to a markdown file **outside your working folder** — a path worked out from your own home directory at run time, for example `~/Documents/Gorilla-OSINT-Dossiers`. The reason is blunt: working folders are very often git repositories, and a private question must never end up in a public commit. Dossier helpers also work under standing orders to keep personal identifiers out of search queries — queries travel to the sites they reach, so the discipline is to generalise first: the pattern, not the person. One source, SEC EDGAR, sends a contact email address as its identification, because the SEC's fair-access policy requires callers to identify themselves; the maintainer's public git email is what is sent. Nothing else changed about what leaves your machine, and no telemetry was added.

### How to Install

**Before you start:**
- Debian, Ubuntu or Mint for the .deb; Arch or CachyOS for the pacman package; any Linux for the tarball.
- `python3` on your machine if you want search to work — the search engine ships inside the program, but it runs on python3.

**Step 1:** Install the package.
```
sudo apt install ./gorilla-opencode_0.1.88_amd64.deb
```
✓ apt finishes without asking you to fix anything.

**Step 2:** Confirm you are running the version you installed, and that the system agrees.
```
gorilla-opencode --version && dpkg -l gorilla-opencode | tail -1
```
✓ Both say 0.1.88. If they disagree, an older copy is still first on your PATH.

**Step 3:** Start the program and ask it to find something in a folder of code.
```
gorilla-opencode
```
✓ It answers with the matching lines and the code around them, in one step, without opening a whole file first.

**Step 4:** Open `/context`.
✓ Every row starts with a reverse-video ON or OFF badge. Pressing space on a row visibly flips it. The rows are in alphabetical order.

**Step 5 (optional):** If you want the dossier tool, find the red "Serious OSINT dossier — EXPENSIVE" row in `/context` and switch it on. Then type `/osint` on its own to read the capability page before spending anything.
✓ A full-screen page appears. No money has been spent.

**To go back:** Install the previous package over this one: `sudo apt install ./gorilla-opencode_0.1.87_amd64.deb`. Note that if you are reinstalling the *same* version number after a rebuild, apt will keep the binary it already has — you need `apt install --reinstall`.

### If Something Goes Wrong

**You installed a new build and the version did not change.**
apt keeps the installed binary when the version string is identical.
What to do: `sudo apt install --reinstall ./gorilla-opencode_0.1.88_amd64.deb`. This caught the developer twice during this cycle.
Status: apt behaving as documented, not a bug here

**Leftover "Generating…" lines stranded in your scrollback, footer text painted over.**
Reported by an Arch/CachyOS tester on v0.1.87. It has not been reproduced on the development machine, so it is not fixed in this release.
What to do: Report your terminal emulator, your font and your `$TERM` value — that is what is missing to confirm the cause.
Status: open, written up in `TO.DO.TO.FIX/arch-tester-stranded-frame-lines.md`

**A search says TRUNCATED.**
Results are capped at 32 KB. This is deliberate: every tool result is re-sent on every later message, so an unbounded one is a recurring bill, not a one-off.
What to do: Narrow the search. The cap always announces itself rather than handing back a silent fragment.
Status: working as intended

**Your old conversations are not in the history list.**
Unchanged since v0.1.85 — the conversation store moved and the old files were not carried across.
What to do: The old files are safe in the old folder. This version still does not read them.
Status: deferred, no migration yet

### Common Questions

**Q: The program got bigger. Isn't that the wrong direction?**
A: It got 252 KiB bigger, and this document says so with the exact byte counts rather than writing "smaller, faster, better". What got smaller is the thing you pay for repeatedly: the conversation. Tool descriptions dropped from 1,388 to 1,279 tokens per message, one search call replaced the search-then-open-the-whole-file chain, and results are capped. The fat moved out of the recurring bill and into a one-off download. That is always the direction you want it to move.

**Q: Why does the search engine ride inside the program?**
A: So a bare downloaded binary can search on any machine that has python3 — nothing to install, nothing to configure, nothing that only exists on the developer's computer.

**Q: Does `/osint` cost me anything if I never arm it?**
A: No. It is off, and the extra instructions it adds are only offered to the model while it is armed.

**Q: How is `/osint` different from `/research`?**
A: `/research` is one pass with evidence tiers, on by default, modest cost. `/osint` runs the same lanes under full dossier discipline: every claim graded on two axes, echoed reports traced back to their one true origin, one bounded follow-up round, and a formal written product. It is off by default and warns you in dollars.

**Q: What is "two-axis grading"?**
A: Two separate letters and numbers instead of one trust score. A–F says how reliable the outlet is; 1–6 says how solid this particular claim is. They are graded apart because they fail apart — a reliable outlet can carry a wrong claim, and an unknown blogger can be right. A single combined score hides exactly that.

**Q: 985 sources. Are they real?**
A: They are listed, every one, in `docs/OSINT-SOURCE-CATALOG.md`, which ships in the package and is generated from the registry file rather than written by hand.

### Bottom Line

Searching your code now costs one message instead of two, and the numbers behind that claim are published rather than asserted: 16 + 1,829 tokens plus a ~10,000-token relaunch, against 132 tokens in one turn. The program file grew by 252 KiB and this document says so plainly instead of claiming it shrank. The transcript no longer hides what tools did; `/context` no longer describes a switched-on feature as "off"; the packaging scripts now refuse to label a binary as a version it does not report. And there is a new upper gear for research, `/osint`, which ships switched off, is armed by hand, warns you in dollars per minute before it runs, and writes its dossier outside your working folder so a private question cannot land in a public repository. The honest limits: the burn-rate figure is a calculation from three stated assumptions and not a measurement; an Arch tester's display bug is reported and unreproduced; and one source sends a maintainer's email address because the SEC requires it.

## Developer track

### Summary

Six commits. The search subsystem is replaced: `ls`, `glob` and `grep` are retired as `*.go.retired` and one `find` tool takes their place, backed by pfind 3.2.0 vendored at `internal/llm/tools/pfind.py` and `go:embed`'ded, resolved GORILLA_PFIND → PATH pfind → embedded cache with a content-hash check. Scrollback readiness moves from `ScrollbackReady` to `ScrollbackSettled`, so a tool-using turn is printed only once its results exist. The websearch tool description is built at startup from the actual backend state instead of a static string that warned "probably not configured" on every turn. Four keyless backends are added (GDELT, World Bank documents, HDX, SEC EDGAR full-text) and an embedded source atlas rides in research helper prompts, backed by a 985-source registry. The research tool's lane prompts gain the OSINT collection cycle. `/context` rows are rewritten around an ON/OFF badge and sorted alphabetically at display time, with the toggle resolving through the same sorted view. `/osint` is added as its own command with its own loadout row, gate and capability page, and the research tool gains `doctrine=dossier`, offered in the schema only while armed and refused at Run when not. `FlexInt` accepts losslessly-convertible string and float integers. Both packaging scripts now refuse to package a binary whose `--version` disagrees with the requested version. 26 Go test packages, all green.

### Known Alternatives Considered

Keeping the three tools and improving `grep` was rejected on measurement: three overlapping tools force a tool-choice decision on every search, and the 2026-08-14 record in `toolname.go` shows a 10-helper run on `local.meta/muse-glimmer-30b` returning nothing, with 30 of 44 calls failing as `ls<|message|>`, `grep<|message|>` — every failed call billed. Shipping `find` as a minimal schema (3,032 chars, 758 tok/turn) was rejected in favour of exposing pfind's full arsenal (5,117 chars, 1,279 tok/turn), on the grounds that the full version still costs less than the trio it replaces and a relaunched failed search costs ~10k tokens; `TestFindDescriptionCostsLessThanTheThreeItReplaced` pins that boundary. Deleting the retired tools was rejected: old session transcripts still render via literal-name cases in `message.go`, and a model calling `grep` by name receives an error that teaches `find`. Making `/osint` an alias of `/research` was rejected — it is a separate command with a separate loadout row, because an alias cannot ship OFF while its parent ships ON. Requiring an API key for research sources was rejected wholesale: all four new backends are keyless. ReliefWeb's API was dropped in favour of HDX because it requires a registered appname; the coverage analysis justifying that swap is recorded in the `searchHDX` override comment rather than left implicit. Finally, the dossier's ONE bounded gap round is a deliberate departure from the doctrine it ports — doctrine allows the cycle to iterate, but the user priced this run at the gate, so an open-ended loop would make that price a lie.

### Architecture Impact

Three invariants move. First, tool count: the agent's search surface is one tool instead of three, and the retired files remain in the tree as `.go.retired` so the removal is auditable rather than a deletion. Second, scrollback readiness now means "will not change again **and** its results exist" rather than "the stream ended" — with an anti-stall belt so turns that ended canceled, errored or permission-denied print immediately with whatever state they reached, because scrollback cannot be reprinted and a transcript must never hang behind a dead call. Third, `/context` display order and toggle order are now the same sorted view, with a test that fails if they ever disagree; this is a correctness invariant, not cosmetics — the previous arrangement could toggle a row other than the one under the cursor. Tool schema shape changes at the edge only: `FlexInt` widens integer parameters to accept losslessly-convertible strings and floats while still rejecting `"abc"` and `100.5`. The research tool's schema is now conditional: `doctrine=dossier` is offered only while the loadout row is armed, and refused at Run when it is not, so the schema cost of the dossier is not charged to users who never turned it on. Packaging gains a hard gate: `build-deb.sh` and `build-arch.sh` execute the binary and compare its `--version` output against the requested version before packaging anything.

### Resource Deltas

Stripped binary 52,125,988 bytes against 51,867,940 for v0.1.87 — +258,048 bytes (+252 KiB, +0.50%). The find-tool swap alone accounted for +131,072 bytes measured at the swap point (51,999,012); the remainder is the four data-source backends, the embedded source atlas, the `/osint` command and its capability page. Retiring `ls`/`glob`/`grep` removed roughly 10 KB of compiled code, against 140,327 bytes of embedded Python. Per-turn description cost falls from 1,388 to 1,279 tokens. Result bytes are bounded at 32 KB per call, 3 match-blocks per file, 15 files, 500 chars per line, 30 s wall clock, with a 400 KB absolute backstop in `NewTextResponse`. RSS and cold start are not measured for this release.

### Known Issues

**[medium]** Stranded frame lines: leftover "Generating…" spinner rows in scrollback and footer text painted over. (reported on v0.1.87, not reproduced, not fixed)
- Cause: Unknown. The working hypothesis is that the reporting terminal renders the spinner glyph wider than the layout library counts it, so each repaint under-erases by a row — the same failure class as the over-wide-line bug, with a glyph-width cause rather than a string-length one.
- Remedy: None yet. Confirming it needs the reporter's terminal emulator, font and `$TERM`. Written up in `TO.DO.TO.FIX/arch-tester-stranded-frame-lines.md`.

**[medium]** apt reports success but the installed binary is unchanged after a rebuild.
- Cause: apt keeps the installed binary when the version string has not changed. This bit the developer twice during this cycle.
- Remedy: `sudo apt install --reinstall ./gorilla-opencode_X.Y.Z_amd64.deb`, then confirm against `gorilla-opencode --version`, not against apt's output.

**[medium]** A package's label disagrees with the binary inside it. (fixed in this release; recorded because it shipped twice before it was caught)
- Cause: On 2026-08-17 `build-deb.sh` wrapped a stale `~test8` binary as `~test9` and again as `~test10`. dpkg reported the new version; the installed binary reported the old one. Found by executing the binary extracted from the package, not by reading a label.
- Remedy: Both `build-deb.sh` and `build-arch.sh` now run the binary and compare `--version` against the requested version, exiting 1 on mismatch. Proven in both directions: mismatch exits 1, match exits 0.

**[low]** The `/osint` gate's dollars-per-minute figure is a calculation, not a measurement.
- Cause: It rests on three unmeasured assumptions — steps per helper, tokens out per step, seconds per step. They are printed on the gate screen beside the number so they can be argued with.
- Remedy: Replace them with real run telemetry. None exists yet.

**[low]** SEC EDGAR requests carry a maintainer contact email as User-Agent.
- Cause: SEC fair-access policy requires callers to identify themselves with a contact address.
- Remedy: One line to change if a different contact is wanted. Dropping the source is the only alternative; no free substitute for full-text filings exists among the 985.

**[low]** A model that calls `grep`, `glob` or `ls` by name gets an error rather than a result.
- Cause: Deliberate. The retired tools are gone from the schema; the error text names `find` and tells the model to retry with it. Matching is exact — the no-fuzzy rules in `toolname.go` are untouched.
- Remedy: None wanted. The mistake costs one small error message instead of a dead investigation.

**[medium]** Old conversations are missing from the history list. (deferred to unscheduled)
- Cause: Unchanged from v0.1.85: the session store moved and the previous files were not migrated.
- Remedy: The old files remain in the old location. No migration exists.

**[low]** `TestExactLongPromptWrapsAtTerminalWidth` passes against a reverted fix. (deferred to unscheduled)
- Cause: Unchanged from v0.1.86: the test is vacuous with respect to `measuredRows()`.
- Remedy: Write a screen-driven regression test.

Find the matching line in the original to verify.
