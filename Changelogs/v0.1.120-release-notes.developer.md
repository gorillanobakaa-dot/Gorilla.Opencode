# Windows port: shell default, PowerShell result reporting, prefix-cache invalidation, IsAbs path guards, and two scrollback rendering faults

**Version:** 0.1.120
**Date:** 2026-09-01

---

## Summary

The program had never functionally run on Windows. The root cause was in internal/config/config.go setDefaults, which set shell.path unconditionally from SHELL with a /bin/bash fallback; because that default was always applied first, the existing Windows shell-detection code was unreachable. Measured before the fix: 0 of 10 bash tool invocations succeeded. Fixing that exposed a second layer in internal/llm/tools/shell/shell.go, which drove PowerShell but parsed results as bash — exit codes were always 0, stderr was always empty, and a UTF-8 BOM was written into the file recording the working directory. That package had zero tests, which is why the faults shipped; it now has 15. The remaining work falls into four groups: two path-comparison security guards that relied on filepath.IsAbs and were therefore bypassable on Windows; a prompt-cache invalidation caused by per-turn mutable content in the system prefix; build reproducibility, where CRLF checkout changed the bytes of go:embed'd prompt text; and two TUI rendering faults reported by the owner from a real session. Scope: Windows is the target; Linux behaviour is preserved and two Linux regressions introduced during the shell rewrite were caught and reverted before release.

## Known Alternatives Considered

Documented in source comments. For the alternate-screen fault, the alternative considered and rejected was keeping the buffer switch and resetting the renderer's line counter on exit; that was rejected because the counter is private to bubbletea and neither repaint() nor clearScreen() resets it, so there is no public lever — recorded in the bufferCmd comment in internal/tui/overlay_state.go. For the CRLF fault, `text=auto` alone was rejected in favour of `eol=lf` because auto still hands Windows CRLF, and this project embeds prompt text at build time — recorded in .gitattributes. For the working tree itself, `git add --renormalize .` was considered and deferred because it would touch nearly every file in one commit. Other rationale is not available in the source material.

## Architecture Impact

Three invariants changed. (1) Dialogs no longer imply an alternate-screen round trip; the frame is composited inline and grows to the dialog's height, which makes bubbletea's cursor-up erase arithmetic self-consistent because the counter then describes rows the frame actually drew. (2) The system prompt prefix is now required to be byte-stable across turns; anything per-turn mutable placed in the always-on environment block silently costs the whole cached prefix. (3) The working tree is pinned to LF, because embedded content must not depend on which machine compiled the binary. A fourth, smaller one: overlay compositing is now centralised in a single appModel.placeOverlay helper instead of duplicated at 28 call sites.

## Subsystem Changes

**TUI:** Dialogs composited inline instead of on the alternate screen; overlay placement centralised into placeOverlay; ctrl+a bound to transcript copy; ctrl+y no longer enables mouse tracking outside the alternate screen. Net effect on tui.go is 376 lines changed for a reduction of roughly 294, almost all of it the 28 collapsed blocks.

**OTHER:** Shell execution rewritten for PowerShell with truthful exit codes and stderr; config no longer forces a POSIX shell; API keys with control characters rejected at load.

**AUTH:** Two workspace path guards that used filepath.IsAbs were bypassable on Windows and now resolve rooted paths against the working volume.

**NETWORK:** Local model probing moved off http.DefaultClient onto a client with a timeout.

**STORAGE:** No changes to session storage or its schema. Conversations are unaffected by install or rollback.

## Security Posture

Attack surface reduced. Two workspace-escape guards that were bypassable on Windows via a POSIX-style rooted path are closed; both failed open on Windows only and were correct on Linux. API keys containing control characters are now rejected before use instead of transmitted — this was live, with a stored key consisting of nine NUL bytes. No CVEs are involved, no dependency was added for security reasons, and no permission or telemetry behaviour changed. github.com/atotto/clipboard moved from an indirect to a direct dependency; it was already in the module graph and no new module was introduced.

## Known Issues

**[medium]** /review fails immediately; TestEveryModuleTheToolkitImportsIsEmbedded fails with "open toolkit/code_review.py: file does not exist". (deferred to unscheduled — blocked on obtaining the file)
- Cause: The analyser was removed from the repository by .gitignore's *.py rule and is absent from this machine as well as from the tree.
- Remedy: Restore the file from a checkout that predates the ignore rule, or from a machine that still holds a copy, then commit it. The ignore rule itself was fixed in 401315e.

**[low]** gofmt -l reports every file in the tree as unformatted. (deferred to a separate renormalisation commit)
- Cause: The working tree still holds CRLF from a checkout made before .gitattributes existed. The files are formatted correctly; only the line endings differ.
- Remedy: Compare ignoring line endings, or run git add --renormalize . in a dedicated commit. Deliberately not done here because it would touch nearly every file and bury this release's changes.

**[medium]** A future release silently loses prompt-cache reuse and nobody notices. (deferred to unscheduled)
- Cause: cache_read_input_tokens is not surfaced anywhere in the interface, so the only way to detect the regression is to time two turns by hand.
- Remedy: Surface the cached-token count in /context. Not implemented in this release.

**[low]** First reply on a local model takes several minutes.
- Cause: Prefill is compute-bound and was measured at 13 to 15 tokens per second on an i7-1255U, a 15 watt part. This is hardware, not a defect.
- Remedy: Keep the inference server resident between sessions so its KV cache survives, and avoid submitting long build logs verbatim. No software change addresses it.

**[low]** Prompt caching behaviour on providers other than Anthropic is unverified. (deferred to unscheduled)
- Cause: Only the local llama.cpp-backed path and the Anthropic path were measured; the others were reasoned about.
- Remedy: Measure before claiming. This release makes no numeric claim about them.
