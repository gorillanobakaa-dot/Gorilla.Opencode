# Windows port: shell default, PowerShell result reporting, prefix-cache invalidation, IsAbs path guards, local-model discovery, and three cursor-arithmetic rendering faults

**Version:** 0.1.120
**Date:** 2026-09-02

---

## Summary

The program had never functionally run on Windows. The root cause was in internal/config/config.go setDefaults, which set shell.path unconditionally from SHELL with a /bin/bash fallback; because that default was always applied first, the existing Windows shell-detection code was unreachable. Measured before the fix: 0 of 10 bash tool invocations succeeded. Fixing it exposed internal/llm/tools/shell/shell.go, which drove PowerShell but parsed results as bash -- exit codes always 0, stderr always empty, a UTF-8 BOM written into the file recording the working directory. That package had zero tests, which is why the faults shipped; it now has 15. The remainder falls into five groups: two path-comparison security guards that relied on filepath.IsAbs and were bypassable on Windows; a prompt-cache invalidation caused by per-turn mutable content in the system prefix; build reproducibility, where CRLF checkout changed the bytes of go:embed'd prompt text; local-model discovery, which hid vision models, discarded load state and counted one server as two; and three rendering faults whose root cause is the renderer's cursor arithmetic. Scope: Windows is the target; Linux behaviour is preserved and two Linux regressions introduced during the shell rewrite were caught and reverted before release.

## Known Alternatives Considered

Documented in source comments. For the alternate-screen fault, keeping the buffer switch and resetting the renderer's line counter on exit was considered and rejected: the counter is private to bubbletea and neither repaint() nor clearScreen() resets it, so there is no public lever -- recorded in the bufferCmd comment in internal/tui/overlay_state.go. For unknown tool parameters, a hard error was considered and rejected in favour of a warning appended to the result: a model that keeps attaching a harmless field would loop forever, unable to complete a call that would otherwise have worked. For the context pressure, trimming the ~4,700 tokens of tool descriptions was considered and rejected, because two faults in this same release were fixed by giving the model MORE guidance; raising the window costs 0.9 GB and cutting guidance costs correctness paid for. For load/eject from the picker, building it was rejected: POST /api/v1/models/load is not idempotent and starts a second copy of a resident model, measured, and the unload endpoint rejects every payload shape tried with a bare HTTP 400 and an empty body, so its schema cannot be established by probing. For CRLF, `text=auto` alone was rejected in favour of `eol=lf` -- recorded in .gitattributes.

## Architecture Impact

Five invariants changed. (1) Dialogs no longer imply an alternate-screen round trip; the frame is composited inline and grows to the dialog's height, which makes the cursor-up erase arithmetic self-consistent because the counter then describes rows the frame actually drew. (2) Every printed line must begin with a carriage return: the renderer emits one for the frame but never for queued Println lines, and CursorUp changes the row without changing the column. (3) The system prompt prefix must be byte-stable across turns; anything per-turn mutable in the always-on environment block silently costs the whole cached prefix. (4) The working tree is pinned to LF, because embedded content must not depend on which machine compiled the binary. (5) A local model is a legitimate fallback for an agent, so the local-only configuration is no longer a startup failure. Two smaller ones: overlay compositing is centralised in a single placeOverlay helper instead of duplicated at 28 call sites, and endpoint identity is decided by a canonical URL instead of a raw string.

## Subsystem Changes

**TUI:** Dialogs composited inline instead of on the alternate screen; every printed line begins at column 0; overlay placement centralised; ctrl+a copies the transcript; ctrl+r re-scans local runtimes; ctrl+y no longer breaks drag selection.

**OTHER:** Shell execution rewritten for PowerShell with truthful exit codes and stderr. Tool errors name the remedy. Unknown tool parameters are reported back to the model.

**AUTH:** Two workspace path guards that used filepath.IsAbs were bypassable on Windows and now resolve rooted paths against the working volume. API keys containing control characters are rejected at load.

**NETWORK:** Local model probing moved off http.DefaultClient onto a client with a timeout. Endpoint identity is decided by canonical URL, so loopback spellings are one server.

**STORAGE:** No changes to session storage or its schema. Conversations are unaffected by install or rollback.

## Test Coverage

- **Added:** 15 tests for internal/llm/tools/shell, which had none. endpoint_dedup_test.go pins loopback folding while keeping ports and LAN addresses distinct. unknownparams_test.go covers the invented-parameter case, including against the real view tool. printline_test.go asserts every printed line starts at column 0 and fails if anything calls tea.Println directly. local_state_test.go pins load state and the context-window fallback order. internal/plain/commandnames_test.go verifies the plain-mode command list against the dispatcher by parsing the switch labels out of the source.
- **Removed:** TestFrameIsFullScreenWhileAnOverlayIsOpen and TestOpeningAndClosingADialogSwitchesBuffers, both of which asserted the behaviour this release deliberately removes. Replaced instead of deleted.
- **Notes:** Suite failures went from 62 to 1 over this release. The one remaining is TestEveryModuleTheToolkitImportsIsEmbedded on the missing toolkit/code_review.py. Separately, TestASlowStreamIsNeverCut in internal/llm/provider is timing-sensitive and flakes when the machine is loaded; it passed 3 of 3 in isolation and was not investigated further. Worth stating plainly: eight of the faults in this release were found by using the program against a slow local model, not by testing. Three were about where text landed instead of what it said; four only reproduce in a local-only configuration the fixtures never had; two are about what a weak model infers, which nothing automated can check.

## Security Posture

Attack surface reduced. Two workspace-escape guards that were bypassable on Windows via a POSIX-style rooted path are closed; both failed open on Windows only and were correct on Linux. API keys containing control characters are rejected before use instead of transmitted -- this was live, with a stored key consisting of nine NUL bytes. No CVEs are involved and no permission or telemetry behaviour changed. github.com/atotto/clipboard moved from indirect to direct; it was already in the module graph and no new module was introduced.

## Known Issues

**[medium]** /review fails; TestEveryModuleTheToolkitImportsIsEmbedded fails with "open toolkit/code_review.py: file does not exist". (deferred to unscheduled -- blocked on obtaining the file)
- Cause: The analyser was removed from the repository by .gitignore's *.py rule and is absent from the working machine as well as from the tree.
- Remedy: Restore the file from a checkout predating the ignore rule, or from a machine that still holds a copy, then commit it. The ignore rule itself was fixed in 401315e.

**[low]** gofmt -l reports every file in the tree as unformatted. (deferred to a separate renormalisation commit)
- Cause: The working tree still holds CRLF from a checkout predating .gitattributes. The files are formatted correctly; only line endings differ.
- Remedy: Compare ignoring line endings, or run git add --renormalize . in a dedicated commit. Deliberately not done here because it would touch nearly every file and bury this release's changes.

**[medium]** A future release silently loses prompt-cache reuse and nobody notices. (deferred to unscheduled)
- Cause: cache_read_input_tokens is not surfaced anywhere, so the only way to detect the regression is to time two turns by hand.
- Remedy: Surface the cached-token count in /context. Not implemented.

**[low]** TestASlowStreamIsNeverCut fails during a full-suite run. (deferred to unscheduled)
- Cause: The stall guard is timing-sensitive and the assertion is missed when the machine is loaded. Passed 3 of 3 in isolation on a machine also hosting a model server.
- Remedy: Re-run the package alone before treating it as a regression. Root cause not investigated.

**[low]** The bottom row of the window sits behind the Windows taskbar.
- Cause: The usable desktop height is not an integer multiple of the console cell height -- 1032 px at 16 px per row is 64.5 rows -- and maximising rounds the row count up. The console reports the rounded-up count and the program believes it.
- Remedy: Drag-resize instead of maximise; the console snaps to whole cells. Or choose a font size that divides the usable height exactly. Not detectable from inside the program.

**[low]** Prefill on a local model is slower than a parameter count suggests.
- Cause: Prefill does not scale with active parameters. Four predictions were made from parameter counts during this work and all four were wrong, one by 2.5x; the model with the fewest active parameters was not the fastest. Thread count is also nearly flat: 1 thread 33.96 tok/s, 4 threads 41.29.
- Remedy: Measure on the target hardware. No speed claim in this project may be derived from a parameter count, an architecture name, or another model's measurement.
