# Gorilla OpenCode 0.1.155: Mac, Windows and Linux

**On Windows the AI now knows the machine it is on, has its own tools for files and for Windows itself, and stops everything it started when you stop it.**

## What is this program?

Gorilla OpenCode is a program you talk to by typing. You write what you want in
ordinary words, for example *find out why this program will not start*, and an
AI does the work: it opens the files on your computer, runs commands, reads what
they print, and tells you what it found.

It is free. It has no account of its own. You choose which AI it uses: one that
runs entirely on your own computer, or one from a company you have a key or a
sign-in for. It is built to work on an old laptop with slow, expensive internet.

## Should you download this version?

**Yes, if you use it on Windows.** This is the Windows release. The AI is told
which Windows, which PowerShell and which tools this computer has. It gets one
tool for copying, mirroring, renaming and deleting files (robocopy with up to
128 threads, a preview before anything is deleted for good, the Recycle Bin by
default) and one read-only tool for services, the event log, the registry and
scheduled tasks. Stopping a command now ends every program it started, and
keeps your PowerShell session. Files PowerShell wrote are read instead of
refused as "binary". Your sign-ins are encrypted for your Windows account.

**Yes, if you use it on Linux or a Mac, for the fixes:** a crashed add-on tool
server (MCP) no longer leaves the chat waiting forever; ChatGPT over a weak
connection tries again when the first connection fails; letters typed while the
program opens are no longer lost; web search can work without installing lynx
(off until you turn it on). The new files tool also works there, with fewer
features. Nothing Windows-only changes for you.

**Know before you update:** the Windows program is not signed. No
code-signing certificate exists yet; getting one is an open decision of the
owner. If you go
back to an older version after this one has saved your sign-in, the older one
asks you to sign in again.

## Why this matters to you

The owner tried the program on Windows with AIs running on the laptop itself and
found they did not know their own tools: not robocopy's 128 threads, not file
attributes, not which PowerShell they were typing into, because all they were
told was "Platform: windows". Stopped commands left programs running unseen.
This version fixes that, and was then checked with 35 everyday requests typed
into the real program, each scored from what ended up on the disk: 33 of 35
were right. The two misses were the AI's own choices, and both are written up
below.
