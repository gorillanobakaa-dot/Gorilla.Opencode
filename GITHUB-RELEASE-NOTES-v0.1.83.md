# v0.1.83 — research tool painted bright red in /context

The `Research (multi-agent)` row in the `/context` menu is now displayed in
bright red bold text.

**Why:** Research is not like any other tool in that list. Every other tool does
one thing per turn. Research can silently trigger up to ten full AI sessions per
question. On a metered connection or a free-tier quota that is real money and
real quota — and it was sitting in the list looking identical to the grep tool.
The red makes it impossible to miss. You see it, you know what it is, and you
decide consciously whether it stays on.

**What did not change:** Keyboard navigation and toggle behaviour are identical.
Selecting the row with the cursor highlights it in the normal way. No other tool
row is affected.
